⚙️ Konfiguracja Firebase (jednorazowo)

Żeby rezerwacje działały u wszystkich osób, ustaw darmową bazę Firebase (ok. 5 minut):

  1. Wejdź na console.firebase.google.com i zaloguj się kontem Google.
  2. Kliknij Dodaj projekt → nazwij np. „warsztaty-dynie” → dalej (możesz wyłączyć Analytics).
  3. W projekcie: Build → Realtime Database → Create Database → wybierz lokalizację (Europe) → Start in test mode.
  4. Wróć do głównego widoku projektu → kliknij ikonę </> (Web) → zarejestruj aplikację (nazwa dowolna) → skopiuj obiekt firebaseConfig.
  5. Otwórz plik index.html w edytorze i wklej swój config w miejscu oznaczonym // === TUTAJ WKLEJ SWÓJ CONFIG ===.
  6. W Realtime Database → Rules ustaw na 30 dni (lub dłużej): 
    {
  "rules": {
    ".read": true,
    ".write": true
  }
}
  7. Zapisz plik i wrzuć go ponownie na Netlify / GitHub Pages.

Po poprawnej konfiguracji ten banner zniknie automatycznie.
